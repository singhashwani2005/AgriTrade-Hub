Project Architecture

The project follows the MVC (Model-View-Controller) architecture.

Model: Handles application data and database entities.
View: Provides the user interface using Thymeleaf, HTML, CSS and Bootstrap.
Controller: Handles user requests and application flow.
Repository: Manages database operations using Spring Data JPA.

Project Goal

The main goal of AgriTrade Hub is to provide a simple digital platform where farmers and merchants can interact directly and manage agricultural product transactions efficiently.
